# Observability Requirements

| ID | 要件 | 詳細 |
|---|---|---|
| NFR5.1 | 監査ログ形式 | JSON Lines（1操作1行）でローカルファイルに必須出力。後から`jq`等で集計可能な形式とする |
| NFR5.2 | 進捗・エラー表示 | 標準エラー出力に進捗・エラーメッセージを人間可読な形で出力する |
| NFR5.3 | 外部監視統合 | 対象外（CLIツールでありサービス監視の概念がないため） |
| NFR5.4 | ダッシュボード | 対象外 |

## SLI/SLO

常駐サービスではないため、従来的なSLI/SLOは定義しない。監査ログ（NFR5.1）が実行結果の唯一の記録手段であり、その完全性（NFR4.3）がこのツールの「可観測性」の中核である。

## Assumptions & Open Questions

None.
