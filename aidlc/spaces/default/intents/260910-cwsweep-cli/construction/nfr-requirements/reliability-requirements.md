# Reliability Requirements

| ID | 要件 | 詳細 |
|---|---|---|
| NFR4.1 | 可用性SLA/SLO | 設定しない（常駐サービスではなく都度実行のCLIバイナリのため） |
| NFR4.2 | 部分障害時の継続動作 | 単一アカウントでのAPI呼び出し失敗（AssumeRole失敗、一時的なAPIエラー等）は、そのアカウントの処理のみを失敗として扱い、他アカウントのスキャン・処理は継続する |
| NFR4.3 | 監査ログ書き込み失敗時のフェイルセーフ | 監査ログの書き込みに失敗した場合は、実行中の削除/retention変更操作自体を中断する（フェイルオープンにしない） |
| NFR4.4 | データ復旧 | バックアップ/リカバリの概念は対象外。削除されたCloudWatch Logsのログデータ自体の復元はAWS側の制約により不可能であり、本ツールの責務は誤削除の防止であって削除後の復旧ではない |
