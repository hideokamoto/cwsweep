# performance-requirements.md — Unit: cli-foundation

## 適用範囲

本Unitは既存のスキャン／実行経路を再配線するのみで、AWS API 呼び出し回数・
ページネーション・並行度は変更しない。新規の性能要件は **引数解析と
ディスパッチのオーバーヘッド** と **audit 表示** に限定される。

## 詳細要件

| ID | 要件 | 目標 | 検証 |
|---|---|---|---|
| NFR5.1 | 引数解析・サブコマンド分岐は AWS I/O 開始前に完了し、追加の I/O を発生させない | 解析はプロセス起動時に 1 回、ネットワーク・ファイル I/O なし | lib 単体テスト（`parse_from_args`）が I/O なしで完走すること |
| NFR5.2 | `scan` / `clean` の describe-log-groups 呼び出し回数・ページネーション挙動は現行実装と同一 | 追加 API 呼び出し 0 | 既存 `scan_all` モックテストの呼び出し回数アサーションを維持 |
| NFR5.3 | `audit` の整形は entries 件数に対して線形（1 パス） | O(n)、全件をメモリに保持する現行 AuditReader 契約の範囲内 | 単体テストで件数増に対し整形が 1 回の走査で済むことをコードレビューで確認 |

## 非目標

- 大規模監査ログ（数十万行）のストリーミング表示は本intentの範囲外
  （FR4.2 フィルタなし・全件表示、audit-reader Contract 1 でメモリ保持を許容）。
